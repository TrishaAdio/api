Behaviour

  • Naming a model uses that model exactly. An unknown id returns 404 rather than silently substituting another.
  • Omitting model uses the configured default.
  • temperature, top_p, max_tokens and stop are accepted for compatibility but ignored — the engine exposes no equivalents.
  • Streaming is valid SSE, but the answer is generated whole then replayed, so time-to-first-token is unchanged.
  • Token counts are estimates; the CLI reports no usage data.
