Notes

  • Naming a model uses that model exactly. An unknown id returns 404 rather than silently substituting another.
  • Omitting model uses the configured default.
  • temperature, top_p, max_tokens and stop are accepted for compatibility but ignored — the Kiro CLI exposes no equivalents.
  • Streaming is correct SSE, but the answer is produced whole and then replayed, so time-to-first-token is not improved.
  • Token counts are estimates; the CLI reports no usage data.
